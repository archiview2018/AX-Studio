# ARCHIVIEW AX Studio — CAD 버전 변환기

Windows용 **DWG 버전 변환** 및 **DWF / DWFx → DWG 복원 변환** 도구입니다.

## 사용 방법

1. [GitHub Releases](https://github.com/archiview2018/AX-Studio/releases)에서 `ArchiviewAXCadTool.exe`를 내려받아 실행합니다.
2. 상단 토글(`DWG` | `DWF`)과 저장할 AutoCAD 버전 칩(`2018+`, `2013`, `2010`, `2007`, `2004`, 또는 `+` 확장으로 `2000`, `R14`)을 선택합니다.
3. 저장 폴더를 확인하거나 변경합니다.
4. `DWG`, `DWF`, `DWFx` 도면 파일이나 폴더를 대기열에 끌어다 놓거나 `+ 파일 추가`, `+ 폴더 통째로` 버튼을 이용합니다.
5. `변환 시작`을 누릅니다.
   - 원본 도면은 덮어쓰지 않고 안전하게 보존됩니다.
   - 여러 시트가 담긴 `DWF` / `DWFx` 파일은 시트별 개별 `DWG` 도면으로 자동 분리 저장됩니다.

## ODA 변환 엔진 안내

- 최종 `DWG` 생성에는 **ODA File Converter**가 필요합니다.
- 처음 실행 시 변환 엔진이 설치되어 있지 않으면 좌측 사이드바의 `ODA 공식 다운로드` 및 `설치 가이드 보기` 버튼으로 공식 설치 페이지를 안내합니다.
- 본 프로그램은 ODA File Converter 실행 파일을 포함하거나 재배포하지 않으며, 사용자가 공식 경로에서 직접 설치한 변환 엔진을 자동으로 탐색해 연결합니다.

## 변환 엔진이 시작되지 않을 때

사이드바에 「변환 엔진 실행에 필요한 Windows 구성 요소가 없습니다」가 보이거나, 실패 이유가 Visual C++ 재배포 패키지 관련이면 **Microsoft Visual C++ 재배포 패키지**가 없는 상태입니다. 「구성 요소 설치」를 누르면 Microsoft 공식 설치 파일(약 25MB)을 내려받아 설치하며, 관리자 승인 창이 한 번 나옵니다. 설치 파일은 Microsoft 서명을 확인한 뒤에만 실행합니다.

## 자동 버전 알림 및 업데이트

- 프로그램을 실행할 때 백그라운드에서 GitHub 최신 버전을 자동으로 확인하며, **새 버전이 출시된 경우에만 업데이트 안내 팝업**이 표시됩니다(이미 최신 버전이거나 오프라인일 때는 방해하지 않고 조용히 넘어갑니다).
- 좌측 하단 `버전 업데이트 확인` 버튼으로 언제든 수동 확인도 가능하며, SHA-256 무결성 검증 후 자동 교체·재실행됩니다.
- 실행 파일명은 버전이 변경되어도 항상 `ArchiviewAXCadTool.exe`로 유지됩니다.

## 오류 보고

변환에 실패하면 결과 창의 **오류 보고** 버튼을 눌렀을 때만 오류 정보가 ARCHIVIEW로 전송됩니다. 묻지 않으며, 버튼을 누르지 않으면 보내지 않습니다.

보내는 내용에는 오류 내용과 **파일 이름·폴더 경로**가 포함됩니다. **도면 내용(파일 자체)은 보내지 않습니다.** 하루 최대 5번까지입니다.

변환 기록은 PC의 `%LOCALAPPDATA%\ArchiviewAXCadTool\logs`에 남습니다(최신 20개).

## 요구사항

- Windows 10 / 11 (x64) 및 .NET Framework 4.5 이상
- 앱 설정 저장 위치: `%APPDATA%\ArchiviewAXCadTool`
