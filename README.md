# ARCHIVIEW AX Studio CAD 버전 변환기

Windows용 세로형 DWG/DWF 도면 목록 및 버전 변환 도구입니다. 기본 창 크기는 600×1250이며, 창 높이를 조절하면 파일 목록도 함께 늘거나 줄어듭니다. 최소 창 크기 620×900에서 파일 목록은 최소 높이를 유지합니다. 헤더에는 ARCHIVIEW AX Studio 로고와 `캐드 버전 변환기 v0.3`이 표시되고, 오른쪽에 `필요한거 요청하기`와 `버전 업데이트` 버튼이 있습니다. 로고를 누르면 https://www.archiview.studio 가 열립니다.

## 첫 실행 및 ODA 변환기 설치

배포 ZIP에는 ODA 프로그램이나 설치 파일이 포함되지 않습니다. DWG 변환에는 ODA File Converter를 별도로 설치해야 합니다. 앱에서 **ODA 공식 다운로드**를 누르면 [ODA 공식 다운로드 페이지](https://www.opendesign.com/guestfiles/oda_file_converter)가 열립니다. 페이지에서 운영체제별 설치 항목을 확인하고, 앱 옆의 **?** 아이콘을 누르면 캡처 이미지와 설치 안내를 볼 수 있습니다. 이 ARCHIVIEW 변환기 자체는 Windows 전용이므로 Windows PC에서는 Windows x64 MSI를 설치해야 합니다. ODA 설치를 마친 뒤 앱을 완전히 종료하고 다시 실행하면 변환 엔진을 자동 검색합니다. 검색되지 않으면 **실행 파일 위치 지정**을 사용하세요.

ODA File Converter는 공식 문서상 GUI와 명령줄 인터페이스를 제공하며, 앱은 설치된 실행 파일을 숨김 창 옵션으로 백그라운드 실행하고 실행 중 해당 프로세스의 창을 숨깁니다. ODA 사용 조건은 ODA에 직접 확인해야 합니다. [ODA FAQ](https://www.opendesign.com/faq/question/what-are-oda-viewer-and-oda-file-converter)는 비회원의 ODA Viewer 및 File Converter 사용을 비상업적 애플리케이션으로 제한한다고 안내합니다. 사업장 사이트 홍보와 함께 배포하거나 사용하는 경우에는 배포 전에 ODA에 허용 범위를 확인하세요.

## 사용 방법

1. `ArchiviewAXCadTool_v0.3.4.exe`를 실행합니다.
2. 파일 형식에서 DWG를 선택하고 목표 AutoCAD 버전을 선택합니다.
3. 저장 폴더를 입력하거나 **폴더 선택**을 누릅니다.
4. 파일을 목록에 끌어다 놓거나 목록 안의 **파일 선택**을 누릅니다. 목록 하단에서 **선택 제거** 또는 **전체 제거**를 사용할 수 있습니다.
5. 변환 엔진이 없다면 **ODA 공식 다운로드**를 눌러 페이지로 이동하고, **?** 아이콘에서 OS별 선택 안내를 확인합니다. Windows x64 MSI를 설치한 뒤 앱을 종료 후 재실행합니다.
6. **변환**을 누릅니다. 완료되면 버튼 아래에 성공/실패 개수와 저장 위치가 표시됩니다.

변환 결과는 지정한 저장 위치에 저장됩니다. 같은 이름의 결과 파일이 이미 있으면 기존 파일을 덮어쓰지 않고 새 이름을 사용합니다. 선택한 파일 형식, 대상 버전, 저장 위치, ODA 실행 파일 경로는 `%APPDATA%\ArchiviewAXCadTool\settings.ini`에 기억됩니다.

## 버전 확인 및 업데이트

헤더 오른쪽의 **버전 업데이트**를 누르면 현재 앱 버전과 공개 GitHub Releases의 최신 안정 버전을 비교합니다. 새 버전이 있으면 릴리스 노트를 보여주고 사용자가 동의한 경우에만 설치 파일을 받습니다. 업데이트 파일은 `ArchiviewAXCadTool_v<버전>.exe`와 같은 이름 뒤에 `.sha256`이 붙은 체크섬 파일이어야 합니다. 앱은 SHA-256을 검증한 다음 종료하고, 임시 업데이트 절차가 실행 파일을 교체한 뒤 앱을 다시 시작합니다. 기존 파일을 백업하며 다운로드 또는 검증이 실패하면 교체를 진행하지 않습니다.

릴리스는 공개 저장소 [archiview2018/AX-Studio](https://github.com/archiview2018/AX-Studio)의 GitHub Releases에서 읽습니다. 첫 배포 태그와 자산 예시는 `v0.3.4`, `ArchiviewAXCadTool_v0.3.4.exe`, `ArchiviewAXCadTool_v0.3.4.exe.sha256`입니다. 저장소에 릴리스가 없으면 앱은 그 상태를 알리고 업데이트를 진행하지 않습니다. v0.3.3 이하 사용자는 업데이트 버튼이 포함된 v0.3.4를 먼저 수동 설치해야 하며, 이후 공개된 새 버전부터 앱 내 업데이트를 사용할 수 있습니다.

## 버그 제보 및 기능 아이디어

헤더 오른쪽의 **필요한거 요청하기**를 누르면 기본 메일 앱에서 `archiview2018@gmail.com` 앞으로 새 메일을 작성할 수 있습니다. 제목과 버그 제보/기능 아이디어 구분, Windows 및 ODA 버전 입력 양식을 미리 채워 둡니다. 메일은 자동으로 발송되지 않으며 내용을 확인·수정한 뒤 사용자가 직접 보내야 합니다. Windows에 기본 메일 앱이 설정되어 있어야 합니다.

## 요구사항 및 진행 표시

Windows 10/11 및 .NET Framework 4.x가 필요합니다. DWG 변환에는 별도 설치된 Windows용 ODA File Converter가 필요합니다. 진행 표시줄은 파일 처리 상태를 나타내며, 완료 카운트는 처리된 파일 수입니다. ODA CLI가 단일 도면 내부의 정확한 완료 퍼센트를 제공하지 않으므로 해당 퍼센트는 표시하지 않습니다.
