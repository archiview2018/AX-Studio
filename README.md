# ARCHIVIEW AX Studio CAD 버전 변환기

Windows용 DWG/DWF AutoCAD 버전 변환 도구입니다.

## 사용 방법

1. ArchiviewAXCadTool_v0.3.5.exe를 실행합니다.
2. 파일 형식과 저장할 AutoCAD 버전을 선택합니다.
3. 저장 위치를 선택합니다.
4. 변환할 파일을 목록에 끌어 놓거나 파일 선택으로 추가합니다.
5. 변환을 누릅니다.

DWG 변환에는 ODA File Converter가 필요합니다. 앱의 ODA 공식 다운로드 버튼으로 ODA 공식 페이지를 열어 Windows x64 버전을 별도로 설치하세요. 설치 후 앱을 다시 실행하고, 자동으로 찾지 못하면 실행 파일 위치 지정을 사용합니다.

헤더의 버전 업데이트 버튼으로 새 버전을 확인할 수 있습니다. 필요한거 요청하기 버튼은 기본 메일 앱에 의견 양식을 열어 줍니다.

Release에는 실행 파일과 무결성 확인용 .sha256 파일을 제공합니다. ZIP은 선택 사항입니다. ODA File Converter는 이 앱에 포함되지 않습니다.
